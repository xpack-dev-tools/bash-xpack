# The xPack GNU Bash

A standalone, cross-platform (Windows, macOS, GNU/Linux) binary
distribution of GNU Bash,
intended for reproducible builds.

## Project documentation

For information on how to install and use this project, please refer to the
[project website](https://xpack-dev-tools.github.io/bash-xpack/).

## Project source

The source code of the current release is available on
GitHub as [xpack-dev-tools/bash-xpack](https://github.com/xpack-dev-tools/bash-xpack),
the [v5.2.21-1.1](https://github.com/xpack-dev-tools/bash-xpack/tree/v5.2.21-1.1) tree.
